# Issue tracker: Local Markdown

Issues and specs for this repository live under `.scratch/`.

- One feature per directory: `.scratch/<feature-slug>/`.
- The feature specification is `spec.md` in that directory.
- Each implementation ticket is one file under `issues/`, numbered from `01` in dependency order.
- Tickets record blockers and use `ready-for-agent` as their local status when ready.
- No external issue tracker is configured for this repository.
